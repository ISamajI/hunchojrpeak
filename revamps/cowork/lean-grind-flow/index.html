Lean Grind

Work hard, spend light. Every task runs through five phases: take it in, route it to the cheapest tier that can win, run that tier's play, pass the quality gate, then ship and stop.

Phase 3

Run the play

Each tier has its own steps, token savers and a clear signal for when to step up.

Tier 0

Just answer

Questions, advice, ideas, short drafts, quick math.

e.g. a pre-game meal, a caption idea, what a credit score means

Play

  1. Read the question
  2. Answer in chat
  3. Offer one next step only if useful

Save tokens

  • No tools, no files, no task list
  • No headers for short answers

Step up if

  • The answer depends on current facts, then search once
cheapest
Tier 1

Solo

Most real work: edit a file, fix a bug, tweak a page, write a post.

e.g. change Redline Auto's hours, add a drill to HunchoStrat

Play

  1. Find the exact spot (search, not full reads)
  2. Make the smallest edit that works
  3. Check it once
  4. Deliver with a 1–3 sentence note

Save tokens

  • Batch reads and searches together
  • Edit lines, never regenerate whole files
  • Never re-read a file just edited

Step up if

  • It needs deep research or a full rebuild
light
Tier 2

One specialist

A bigger job one branch clearly owns.

e.g. Jiraiya researches restaurants, Kakashi writes the pitch

Play

  1. Write one complete brief
  2. Send it to ONE top-level agent
  3. Skim the result, fix small gaps myself
  4. Deliver

Brief must include

  • Goal and who it's for
  • Files, links, constraints
  • What "done" looks like

Step up if

  • The output is going live or to a client
medium
Tier 3

Full squad

High stakes: client sites going live, new apps, anything with money.

e.g. a new LTGPEAK client launch, the Redline booking system

Play

  1. Planner (Kabuto) maps the build
  2. Henry approves the plan
  3. Executor (Anko) builds it
  4. Itachi reviews once
  5. Fix findings, ship

Guardrails

  • One branch's squad per task, not several
  • Plan is short: steps, files, risks
heavy
Escalation ladder: T0→T1→T2→T3 Step up one rung at a time. Never skip straight to full squad.

Scouting report

Where tokens leak

Wasters

  • Running planner, executor and reviewer on small tasks
  • Reading whole files to change one line
  • Rewriting a full page for a small change
  • Running the same search again
  • Vague briefs that make agents start from zero
  • Several review passes on the same work
  • Long recaps of what was already delivered
  • One giant chat that holds every project

Savers

  • Smallest tier first, step up only when needed
  • Search for the exact line, then edit it
  • Edit in place, keep what works
  • Research once, act on it
  • Complete briefs: goal, files, what done looks like
  • One review, fix, ship
  • Short replies
  • A new chat per project
