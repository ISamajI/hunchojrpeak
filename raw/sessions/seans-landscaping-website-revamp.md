# Sean's Landscaping website revamp

## Summary
A rebuilt demo site for Sean's Landscaping (static site generated by `src/build.mjs`) was pushed to deploy as a Cloudflare Worker through GitHub Actions. The first deploys failed for lack of `CLOUDFLARE_API_TOKEN`; after Henry approved, the workflow was changed to deploy to a temporary anonymous Cloudflare account with a claim link. Henry then asked for an opening animation and upscaling of every photo: Claude added a skippable intro animation and a GitHub Actions job that downloads all ~175 photos from the old WordPress site, AI-upscales the small ones (Real-ESRGAN, 33 upscaled) and serves them locally as webp.

- Readability: stronger gradient behind tile labels on bright skies.

## Workflow / process used
1. Push to branch -> GitHub Actions builds and deploys with wrangler (sandbox cannot reach Cloudflare directly).
2. No token -> temporary account deploy + claim link (only after explicit user approval).
3. Heavy jobs the sandbox cannot do (downloading from the client's old site, AI upscaling) run on GitHub runners; results committed back by the bot.
4. Monitor runs via GitHub API (`Monitor` background watcher), read job logs, fix, rerun.
5. Verify live URL from outside (Firecrawl screenshot/links), run full test suite, then report.
