# Note conventions

**What:** where each kind of note lives and how notes connect.

| Kind | Folder | Naming |
|---|---|---|
| Daily notes / session logs | `raw/` | `YYYY-MM-DD.md` |
| Codified reference | `wiki/` | `kebab-case.md`, one idea per note |
| Published / finished artifacts | `outputs/` | `YYYY-MM-DD-short-name.ext` |

- Link related notes with `[[note-name]]`.
- Every wiki note is listed in [[index]] and links to at least one other note.
- Raw notes are allowed to be messy; durable ideas get promoted into `wiki/`.
