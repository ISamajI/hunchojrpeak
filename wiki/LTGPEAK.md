# LTGPEAK

LTGPEAK ("Time is Quality") is the web-design + dashboard studio: bold, fast sites for local businesses, usually live in 1–2 days. This note collects the studio's own site, pricing, ops tools and sales material.

## Key details

- Brand line: **Time is Quality** — speed is the differentiator.
- Pricing lives in the Pricing Menu + Pricing Calculator; profit split between partners in Profit Split.
- Ops: Crew Board (client change requests), Peak Uptime (hosting watch), Site Pulse (analytics demo), Command Center (visitor site + studio dashboard).
- Sales: Call Sheet (Mercer County cold-call script + lead tracker), Caption Library (12 Instagram captions), Motion Playbook (cinematic web techniques).
- Glow Nail Studio is the fake demo client used to test the change-request flow (v1 → v2 shows a holiday-hours change).
