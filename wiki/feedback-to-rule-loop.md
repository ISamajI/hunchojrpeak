# Feedback-to-rule loop

Render, give a plain note, then: "Fix it, then add this to the skill so it never happens again." The fix becomes a rule, check or script in SKILL.md, so no note is given twice. Keep a note → rule table in the skill.

Apply to the `motion-design` skill: each [[Kimimaro]] finding ships with a new check. Part of [[nate-herk-playbook]].
