# Editing Research

Research project tracking modern video-editing styles going viral across TikTok, Instagram Reels, YouTube (Shorts + long-form), and other platforms.

## Layout
- `raw/` — dated research notes from each research agent (one platform/topic per note)
- `wiki/` — atomic reference articles: one technique or concept per note, linked with [[wiki links]]
- `outputs/` — finished deliverables (trend report, vetted source list)
