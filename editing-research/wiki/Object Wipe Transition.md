# Object Wipe Transition

An object sweeps across the whole frame and hides the cut, revealing a change behind it. The Nov 2026 example is the "Fan Transition": the camera looks straight down at a creator lying still, a giant fan blade sweeps the screen, and each blade reveals a new outfit.

## How to do it
- **Template / quick route (TikTok note):**
  1. Mount the phone directly overhead (see [[Camera POV Reveals]]).
  2. Film the same pose and framing in 3–4 outfits.
  3. In [[CapCut]] or TikTok's editor, add a fan-blade transition (or a masked object wipe) at each cut.
  4. Time the swaps to the audio beats ([[Beat Sync]]).
- **Manual masked-overlay route (Instagram note):**
  1. Film each outfit from the same overhead position. Start each take by clicking a remote.
  2. Add a fan cutout as an overlay layer and keyframe its rotation.
  3. Mask each new outfit clip so it appears behind each blade.
  - [[Edits]] added masks and keyframe animation (Social Media Today, 2026-03-19). Later says an AI editor template is the shortcut.

## Why it works
The hidden cut reads like a magic trick, so viewers stay for each reveal. It packs several products or outfits into one video (New Engen) and has a physical-world VFX feel that is easy to template.
