# Hook AB Testing

Uploading several cuts of the same video, differing mainly in the opening, so the platform tests which one holds attention best. It turns the opening edit into something you can measure. (Filename avoids "/"; the raw notes call it "Hook A/B Testing".)

## How to do it
- **YouTube Studio video A/B testing** (announced "coming soon" on 2026-09-23): up to **three different cuts**. Edit 2–3 versions that differ only in the first 30 s (cold open vs. value statement vs. highlights teaser).
- **[[Edits]]**: "multiple versions of a single reel" so creators can test what performs best (TechCrunch, 2026-06-11).
- Instagram Trial Reels (shown to non-followers first; public Creator/Business account with 200+ followers, via CreatorFlow, secondary) can serve a similar purpose.

## Why it works
Most drop-off happens in the first minute ([[Retention Editing]]), so the hook is the highest-leverage part of the edit.
