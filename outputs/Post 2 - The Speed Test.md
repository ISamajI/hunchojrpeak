# Post 2 - The Speed Test

Part of [[LTGPeak 7-Day Launch Week]]. Thu Nov 12. Reel, 12-15 seconds.

## Status

Not produced. It needs your real PageSpeed score, which has to be recorded on your own phone or laptop.

## The idea

Run Google's own free speed test on a client site, live, and screen-record the score coming in. The grade comes from Google, so nobody has to take your word for it.

## Do this first

Go to pagespeed.web.dev and test all three client sites on Mobile. Use whichever scores best. If none score in the green (90+), fix the sites before posting; don't edit the number. If you want a comparison, test a slow site you mocked up yourself, never a real business.

## Hooks to test

1. "We let Google grade a website we built. Live."
2. "Your web designer says your site is fast. Here's how to check in 20 seconds."
3. "This free Google test tells you if your website is losing customers."

## Shot list

| Time | Shot | On-screen text |
|---|---|---|
| 0-2s | pagespeed.web.dev open, pasting the client's address | Hook line |
| 2-7s | Hit Analyze. The loading bar runs (speed it up 3x) | "Google's own test. Free. Anyone can run it." |
| 7-11s | Score dial fills green. Slow zoom on the number | The real score, large |
| 11-14s | The site scrolling on a phone | "Built phone-first. Test yours, then DM DEMO." |

## Edit notes

## Why it works

It teaches a check any owner can run in 20 seconds, so they save it and send it. Everyone who tests their own site and scores badly has a reason to DM you.
