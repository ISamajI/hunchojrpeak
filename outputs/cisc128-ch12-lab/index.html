Phase 1

Before you start

In the book this is "planning the installation." Check your hardware and gather what you need.

  1. 1

    Make sure your host can run a VM

    • Hardware virtualization (Intel VT-x or AMD-V) has to be on in the host's BIOS/UEFI.
    • VirtualBox is a Type 2 hypervisor, meaning it runs on top of a host OS. That's a likely quiz question.
    • Leave the VM about 4 GB of RAM and 50 GB of free disk space.
    Host check
    VirtualizationEnabled
    Free RAM≥ 4 GB
    Free disk≥ 50 GB
  2. 2

    Get the Windows 10 ISO

    • Use the ISO your class gave you, or download it from Microsoft's Windows 10 download page (Media Creation Tool, or a direct ISO).
    • Choose 64-bit (x64). A 32-bit install can only use 4 GB of RAM.
    • Note where you save the .iso. You'll attach it in the next phase.

  1. 3

    • Check Skip Unattended Installation. You'll go through Setup by hand, which is the part the lab is about.

    Hardware: memory and CPUs

Phase 3

Windows Setup: the clean install

You're doing a clean install onto an empty drive, not an upgrade.

  1. 6

    Start the VM and boot from the ISO

    • Select the VM and click Start. It boots from the ISO. If you see "Press any key to boot from CD," press a key.
    • Set language, time format, and keyboard, then click Next and Install now.

    Custom install and pick the drive

Phase 5

Finish and verify

These are the book's post-installation tasks. Confirm everything works before you call it done.

  1. 11

    Install Guest Additions

    • In the VirtualBox menu, go to Devices → Insert Guest Additions CD image.
    • In File Explorer, open the CD drive and run VBoxWindowsAdditions.exe. Accept the prompts, then reboot.
    • Afterward the screen resizes properly and your mouse moves in and out of the VM smoothly.

  2. 12

    Check edition, drivers, and updates

    • Settings → System → About: confirm the edition and "64-bit operating system." You can also run winver.
    • Device Manager (right-click Start): no yellow warning icons should show.
    • Settings → Update & Security → Windows Update: click Check for updates.

Quiz prep

Chapter 12 ideas to know

The concepts behind what you just did. The Ch 12 quiz will likely draw from these.

Clean install

Windows goes onto an empty or wiped drive, and nothing is kept. That's what you did in the lab.

In-place upgrade

Installs over an existing Windows and keeps apps, settings, and files.

Repair installation

Reinstalls Windows over itself to fix corrupted system files and keeps your data.

Unattended install

Setup gets its answers from an answer file (autounattend.xml), so nobody has to click through.

Image deployment

You capture a configured PC as an image and push it to many machines. Sysprep strips the unique IDs first.

Network / PXE boot

The PC boots from the network card and pulls the install from a deployment server.

Multiboot

Two or more operating systems on one PC, each on its own partition. You pick one at startup.

Type 1 vs Type 2 hypervisor

Type 1 runs right on the hardware (Hyper-V, ESXi). Type 2 runs inside a host OS (VirtualBox, VMware Workstation).

Workgroup vs domain

A workgroup is a small peer network where each PC manages its own accounts. A domain is managed centrally by Active Directory, which needs Pro or higher.

Local vs Microsoft account

A local account lives only on that PC. A Microsoft account signs in online and syncs settings.
