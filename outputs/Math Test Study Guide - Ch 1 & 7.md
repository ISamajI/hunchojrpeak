## Chapter 1: the rules (1.5–1.7)

Every Chapter 1 problem uses the same three moves: isolate, split into two cases, then shade a number line.

### 1.5 Compound inequalities

- **AND** means both must be true, so the answer is the overlap: one piece *between* two numbers. Example: −3 < x ≤ 1 → (−3, 1].
- **OR** means either can be true, so the answer is both pieces pointing *outward*. Example: x < −1 or x ≥ 5 → (−∞, −1) ∪ [5, ∞).
- For a 3-part inequality like −6 < 3x + 3 ≤ 6, do the same step to all three parts.
- **Multiply or divide by a negative → flip the sign.**
- < or > → open circle and ( ). ≤ or ≥ → closed dot and [ ]. ∞ always gets ( ).

### 1.6 Absolute value equations

|x| is the distance from 0, so it can never be negative.

1. Isolate the absolute value first (move the +8, divide off the 2).
2. |stuff| = a positive number → stuff = a **or** stuff = −a → two answers.
3. |stuff| = 0 → one answer: set stuff = 0.
4. |stuff| = a negative number → **no solution (∅)**.
5. |A| = |B| → A = B or A = −B.

### 1.7 Absolute value inequalities

Memory trick: **"Less thAND, GreatOR."**

- |x| < a → −a < x < a. An AND, shaded *between*.
- |x| > a → x < −a **or** x > a. An OR, shaded *outward*.
- Trick cases: |x| < negative → ∅. |x| > negative → all real numbers.
- To write the inequality from a graph: find the middle point and the distance to each end. Shaded between −c and c → |x| < c (or ≤ with closed dots).

## Chapter 1: worked examples from your review

These are the 7 Chapter 1 questions on the review, solved step by step. Expect the test to look like this.

**Q1. Solve |v| + 8 > 14**

1. Isolate: subtract 8 → |v| > 6
2. "Greater" → OR, outward → v < −6 **or** v > 6
3. Graph: open circles at −6 and 6, arrows pointing away from each other.

**Q6. Solve |6w + 12| = 0**

1. Equals 0 → only one case: 6w + 12 = 0
2. 6w = −12 → **w = −2**

**Q13. Solve |u| − 15 = −15**

1. Isolate: add 15 → |u| = 0
2. **u = 0** (don't stop at "−15 is negative, no solution": isolate first!)

**Q9. Solve −6 < 3x + 3 ≤ 6 and graph it**

1. Subtract 3 from all three parts → −9 < 3x ≤ 3
2. Divide all three parts by 3 → −3 < x ≤ 1
3. Interval: **(−3, 1]**. Open circle at −3, closed dot at 1, shade between.

**Q19. Solve 2v − 3 < −5 or −3v ≤ −15**

1. Left side: 2v < −2 → v < −1
2. Right side: divide by −3 and **flip** → v ≥ 5
3. OR keeps both pieces → **(−∞, −1) ∪ [5, ∞)**

**Q16. Write an absolute value inequality for the graph (shaded between open circles at −2 and 2)**

1. Middle = 0, distance to each end = 2
2. Shaded between + open circles → **|x| < 2**

**Q21. Graph |w| ≤ 4**

1. "Less" → AND, between → −4 ≤ w ≤ 4
2. Closed dots at −4 and 4, shade between them.

## Chapter 7: the rules (7.1, 7.2, 7.4, 7.5)

Chapter 7 is all about quadratics, anything with an x²: you solve them (7.1, 7.2) and graph them as parabolas (7.4, 7.5).

### 7.1 Square root property and completing the square

- **Square root property:** if x² = k, then x = ±√k. Never drop the ±.
- Isolate the squared part first: (x − 3)² = 16 → x − 3 = ±4 → x = 7 or x = −1.
- A negative under the root gives imaginary answers: x² = −9 → x = ±3i.
- **Completing the square** turns the left side into a perfect square:
  1. Move the constant to the right side.
  2. If x² has a number in front, divide everything by it.
  3. Take half the x-coefficient, square it, and add it to both sides.
  4. Factor the left side as (x + half)², then use the square root property.

### 7.2 The quadratic formula

Get the equation into the form ax² + bx + c = 0 first, then:

```
x = \frac{-b \pm \sqrt{b^{2} - 4ac}}{2a}
```

The **discriminant** b² − 4ac tells you what kind of answers you'll get before you solve:

| b² − 4ac is… | You get… |
|---|---|
| Positive | 2 real answers (a perfect square gives fractions, otherwise square roots) |
| Zero | 1 real answer |
| Negative | 2 imaginary answers with i |

### 7.4 Graphing f(x) = a(x − h)² + k

- **Vertex = (h, k).** Watch the sign: (x − 3)² means h = 3, but (x + 3)² means h = −3.
- **Axis of symmetry:** the vertical line x = h.
- a > 0 opens **up**, so the vertex is a minimum. a < 0 opens **down**, so the vertex is a maximum.
- |a| > 1 is narrower than x². |a| < 1 is wider.

### 7.5 Vertex formula and max/min problems

When the function is in the form f(x) = ax² + bx + c:

```
x = \frac{-b}{2a} \qquad y = f\left(\frac{-b}{2a}\right)
```

- y-intercept: plug in x = 0 (it's just c). x-intercepts: set f(x) = 0 and solve.
- Word problems asking for a **maximum height, maximum area or minimum cost** want the vertex: x tells you *when* or *what size*, y is the max or min itself.

Read every parabola the same way: find the vertex, check the sign of a, then use b² − 4ac to know how many times it crosses the x-axis.

## Chapter 7: worked examples

Nine textbook-style problems covering every Chapter 7 section, solved step by step. Cover the answer, try it, then check.

### 7.1 Square root property and completing the square

**Example 1. Solve (x − 3)² = 16**

1. Square root both sides, with ±: x − 3 = ±4
2. x = 3 + 4 = **7** or x = 3 − 4 = **−1**

**Example 2. Solve (2x + 1)² = −9**

1. ±√ both sides: 2x + 1 = ±√(−9) = ±3i
2. 2x = −1 ± 3i → **x = (−1 ± 3i)/2**

**Example 3. Solve x² + 6x − 7 = 0 by completing the square**

1. Move the constant: x² + 6x = 7
2. Half of 6 is 3, and 3² = 9. Add 9 to both sides: x² + 6x + 9 = 16
3. Factor: (x + 3)² = 16
4. ±√: x + 3 = ±4 → **x = 1 or x = −7**

### 7.2 The quadratic formula

**Example 4. Solve 2x² − 3x − 5 = 0**

1. a = 2, b = −3, c = −5
2. b² − 4ac = 9 + 40 = 49
3. x = (3 ± 7)/4 → **x = 5/2 or x = −1**

**Example 5. Solve x² + 2x + 5 = 0**

1. a = 1, b = 2, c = 5 → b² − 4ac = 4 − 20 = −16
2. √(−16) = 4i, so x = (−2 ± 4i)/2 → **x = −1 ± 2i**

**Example 6. How many real answers does 9x² − 12x + 4 = 0 have?**

1. b² − 4ac = 144 − 144 = 0
2. Zero → **one real answer**. (It factors as (3x − 2)² = 0, so x = 2/3.)

### 7.4 Graphing in vertex form

**Example 7. Describe f(x) = −2(x − 1)² + 3**

| Feature | Answer | Why |
|---|---|---|
| Vertex | (1, 3) | h = 1, k = 3 |
| Opens | Down | a = −2 is negative |
| Max or min | Maximum value of 3 | It opens down |
| Axis of symmetry | x = 1 | x = h |
| Width | Narrower than x² | \|a\| = 2 is bigger than 1 |

### 7.5 Vertex formula and applications

**Example 8. Find the vertex and intercepts of f(x) = x² − 6x + 5** (the graph in the diagram above)

1. x = −b/(2a) = 6/2 = 3
2. y = f(3) = 9 − 18 + 5 = −4 → **vertex (3, −4)**, a minimum
3. y-intercept: f(0) = **5**. x-intercepts: (x − 1)(x − 5) = 0 → **x = 1 and x = 5**

**Example 9. A ball's height after t seconds is h(t) = −16t² + 64t + 5 feet. Find the maximum height.**

1. "Maximum" means find the vertex: t = −64 / (2 · −16) = **2 seconds**
2. h(2) = −16(4) + 64(2) + 5 = −64 + 128 + 5 = **69 feet**

## Common mistakes and test-day checklist

Most lost points on this test come from six slips, not from hard problems.

| Mistake | Fix |
|---|---|
| Splitting the absolute value before isolating it | Get \|stuff\| alone first (Q1, Q13) |
| Forgetting to flip when ÷ by a negative | Circle every negative you divide by (Q19) |
| Mixing up AND vs OR on absolute value | "Less thAND, GreatOR" |
| Dropping the ± after a square root | x² = 16 has two answers: 4 and −4 |
| Getting the vertex sign wrong | (x + 3)² means h = −3, not 3 |
| Quadratic formula slips | Write a, b, c first. −b of a negative b is positive. Divide the whole top by 2a |
