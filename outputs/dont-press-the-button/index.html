Level 1 · Beginner

Make it playable

By the end you can press Play and run full rounds with friends in Studio. Tick each step off as you go; your ticks are remembered in this browser.

Step 1

Open Roblox Studio and learn the screen

  1. Go to create.roblox.com, download Roblox Studio for Windows (Windows 10 or 11), install it and sign in with your Roblox account.
  2. On the start screen, choose the Baseplate template. You get a big grey floor and a sky. (The exact wording on the start screen changes now and then; look for “Baseplate”.)
  3. Save straight away with Ctrl+S and call it DON'T PRESS THE BUTTON! Save often.

The five things you will use most

Top bar tabsHome, Model, Avatar, UI, Script, Plugins. Almost everything in Level 1 is on Home: Part, Move/Scale/Rotate, Color, Material, Anchor, Group.
Play controlsIn the top-left of the window (not on a tab). A dropdown picks the mode (Test, Test Here, Run, Server & Clients) and the Play button starts it.
ExplorerA list of every object in your game, in folders. You will add scripts here.
PropertiesThe settings of whatever you selected: size, colour, position…
OutputMessages and errors from your scripts. Keep it open. Red text means something broke, and it tells you the script and line.

Can't see Explorer, Properties or Output? Open them from the Window menu (Output is also on the Script tab). If the toolbar shows only icons, right-click an empty part of the toolbar and turn on Show labels.

Moving the camera

Hold the right mouse button and drag to look around. WASD fly, Q/E go down/up, the scroll wheel zooms, and F jumps to whatever you selected.

Step 2

The arena (and practising with Parts)

The arena is a 10 × 10 grid of floor tiles floating 50 studs up in the sky, with lava underneath and four walls around it. A script called ArenaBuilder builds it from the numbers in GameConfig when the game starts, so the events always line up with the floor. Building 100 tiles by hand would take ages, and one wrong tile would break the vanishing-floor event.

Arena

Floor top at height 50, 80 × 80 studs, walls 40 tall, lava 25 below.

Lobby

A yellow platform on the ground around 0, 1, 110. Everyone waits and respawns here. The Baseplate's own grey SpawnLocation sits under the arena, so the script switches it off for you.

Practise the tools by decorating the lobby

  1. Home → Part adds a block in front of the camera.
  2. Use Move (drag the arrows), Scale (drag the balls) and Rotate (drag the rings). Or type exact numbers into Position, Size and Orientation in Properties. That's what the next step does.
  3. Change Color and Material on the Home tab.
  4. Click Anchor. Anchored parts never fall or get pushed. Anchor everything you build.
  5. Build something near 0, 0, 110 on the Baseplate: an archway, a bench, a “WAIT HERE” sign. Keep the area right around 0, 1, 110 clear, because the lobby platform and spawn go there.

Rename things in Explorer by double-clicking the name (or select it and press F2). Names matter: scripts look for objects by their exact name, capital letters included.

Step 4

The countdown and round system (scripts, part 1)

Now the brain. There are three kinds of script, and putting them in the right place is most of the battle:

ScriptRuns on the server, the one computer that runs the game for everyone. Rules, timers and coins live here. Put it in ServerScriptService.
LocalScriptRuns on each player's device. Only for what that player sees (the on-screen text). Put it in StarterPlayer → StarterPlayerScripts.
ModuleScriptA box of code that other scripts require. It does nothing on its own.

-- RoundLogic (ModuleScript in ReplicatedStorage)
-- Small "thinking" functions with no parts or players in them.
-- Keeping them separate means they are easy to read and easy to test.

local RoundLogic = {}

-- Which difficulty should this round use?
function RoundLogic.GetDifficultyName(config, roundNumber)
	local mode = config.DifficultyMode
	if mode ~= "Escalating" then
		return mode
	end
	if roundNumber >= config.EscalationRounds.Chaos then
		return "Chaos"
	elseif roundNumber >= config.EscalationRounds.Normal then
		return "Normal"
	end
	return "Chill"
end

-- Events that are unlocked by this round.
function RoundLogic.GetAvailableEvents(config, roundNumber)
	local available = {}
	for _, event in ipairs(config.Events) do
		if roundNumber >= event.UnlockRound then
			table.insert(available, event)
		end
	end
	return available
end

-- Pick a random unlocked event, avoiding a repeat of last round when possible.
-- randomNumber is a function returning a number from 0 to 1 (math.random works).
function RoundLogic.PickEvent(config, roundNumber, lastEventName, randomNumber)
	randomNumber = randomNumber or math.random
	local choices = {}
	for _, event in ipairs(RoundLogic.GetAvailableEvents(config, roundNumber)) do
		if event.Name ~= lastEventName then
			table.insert(choices, event)
		end
	end
	if #choices == 0 then
		choices = RoundLogic.GetAvailableEvents(config, roundNumber)
	end
	if #choices == 0 then
		return nil
	end

	local totalWeight = 0
	for _, event in ipairs(choices) do
		totalWeight = totalWeight + event.Weight
	end
	local roll = randomNumber() * totalWeight
	for _, event in ipairs(choices) do
		roll = roll - event.Weight
		if roll < 0 then
			return event
		end
	end
	return choices[#choices]
end

-- How many coins does one player get this round?
function RoundLogic.CalculateReward(config, difficultyName, survived, pressedButton)
	local rewards = config.Rewards
	local coins = rewards.Participation
	if survived then
		coins = coins + rewards.Survive
		if pressedButton then
			coins = coins + rewards.PresserBonus
		end
	end
	local multiplier = config.Difficulties[difficultyName].RewardMultiplier
	return math.floor(coins * multiplier + 0.5)
end

-- The best cosmetic a coin total has unlocked (or nil).
function RoundLogic.GetBestCosmetic(config, coins)
	local best = nil
	for _, cosmetic in ipairs(config.Cosmetics) do
		if coins >= cosmetic.Coins and (best == nil or cosmetic.Coins > best.Coins) then
			best = cosmetic
		end
	end
	return best
end

-- Checks the config for typos and impossible values. Returns a list of problems.
function RoundLogic.ValidateConfig(config)
	local problems = {}
	local function check(condition, message)
		if not condition then
			table.insert(problems, message)
		end
	end

	check(config.MinPlayers >= 1, "MinPlayers must be at least 1")
	check(config.IntermissionTime > 0, "IntermissionTime must be above 0")
	check(config.ButtonPhaseTime > 0, "ButtonPhaseTime must be above 0")
	check(config.ResultsTime >= 0, "ResultsTime can't be negative")

	local mode = config.DifficultyMode
	check(mode == "Escalating" or config.Difficulties[mode] ~= nil, "Unknown DifficultyMode: " .. tostring(mode))
	if mode == "Escalating" then
		check(config.EscalationRounds.Normal < config.EscalationRounds.Chaos, "EscalationRounds.Normal must come before Chaos")
		check(config.Difficulties.Chill and config.Difficulties.Normal and config.Difficulties.Chaos,
			"Escalating mode needs Chill, Normal and Chaos difficulties")
	end

	for name, difficulty in pairs(config.Difficulties) do
		check(difficulty.EventTime > 0, name .. ".EventTime must be above 0")
		check(difficulty.RewardMultiplier > 0, name .. ".RewardMultiplier must be above 0")
		check(difficulty.Flood.RiseTime > 0, name .. ".Flood.RiseTime must be above 0")
		check(difficulty.Flood.MaxHeight > 0 and difficulty.Flood.MaxHeight < config.Arena.WallHeight,
			name .. ".Flood.MaxHeight must be between 0 and the wall height")
		check(difficulty.Floor.WaveInterval > difficulty.Floor.WarnTime,
			name .. ".Floor.WaveInterval must be longer than WarnTime")
		check(difficulty.Floor.KeepTiles >= 1, name .. ".Floor.KeepTiles must be at least 1")
		check(difficulty.Ball.Size > 0 and difficulty.Ball.Size < config.Arena.TileSize * config.Arena.TilesPerSide / 2,
			name .. ".Ball.Size is too big for the arena")
		check(difficulty.Ball.Count >= 1, name .. ".Ball.Count must be at least 1")
	end

	local seen = {}
	local hasRoundOneEvent = false
	for _, event in ipairs(config.Events) do
		check(not seen[event.Name], "Event listed twice: " .. tostring(event.Name))
		seen[event.Name] = true
		check(event.Weight > 0, event.Name .. " needs a Weight above 0")
		check(event.UnlockRound >= 1, event.Name .. " UnlockRound must be at least 1")
		for difficultyName, difficulty in pairs(config.Difficulties) do
			check(difficulty[event.Settings] ~= nil,
				event.Name .. " reads settings '" .. tostring(event.Settings) .. "' but " .. difficultyName .. " has none")
		end
		if event.UnlockRound <= 1 then
			hasRoundOneEvent = true
		end
	end
	check(hasRoundOneEvent, "At least one event must unlock on round 1")

	for i, cosmetic in ipairs(config.Cosmetics) do
		check(cosmetic.Coins > 0, cosmetic.Name .. " needs a coin price above 0")
		check(cosmetic.Rainbow or cosmetic.Color, cosmetic.Name .. " needs a Color (or Rainbow = true)")
		if i > 1 then
			check(cosmetic.Coins > config.Cosmetics[i - 1].Coins, "Cosmetics must be listed cheapest first")
		end
	end

	return problems
end

return RoundLogic

-- RoundManager (Script in ServerScriptService)

--   lobby countdown -> teleport into arena -> 20s "don't press" -> random event -> rewards -> back to lobby

-- Players read these attributes to update their screen (see the HUD LocalScript).
local function setStatus(phase, text, timeLeft)
	ReplicatedStorage:SetAttribute("Phase", phase)
	ReplicatedStorage:SetAttribute("Status", text)
	ReplicatedStorage:SetAttribute("TimeLeft", timeLeft or 0)
end

local function anyoneLeft()
	return next(participants) ~= nil
end

local function eliminate(player)
	if participants[player] then
		participants[player] = nil
		if player.Parent then
			fxRemote:FireClient(player, "Banner", "ELIMINATED!")
		end
	end
end

-- Everyone still alive in the arena, with the parts events usually need.
local function getAlive()
	local alive = {}
	for player in pairs(participants) do
		local character = player.Character
		local humanoid = character and character:FindFirstChildOfClass("Humanoid")
		local root = character and character:FindFirstChild("HumanoidRootPart")
		if humanoid and root and humanoid.Health > 0 then
			table.insert(alive, { Player = player, Character = character, Humanoid = humanoid, Root = root })
		end
	end
	return alive
end

-- Counts down to a fixed finish time (so it never drifts). Stops early (and returns true) if stopWhen() becomes true.
-- makeText(timeLeft) returns the status text, e.g. "Next round in 5..."
local function countdown(seconds, phase, makeText, stopWhen)
	local finish = os.clock() + seconds
	local shown = nil
	while true do
		local timeLeft = math.ceil(finish - os.clock())
		if timeLeft <= 0 then
			break
		end
		if timeLeft ~= shown then
			shown = timeLeft
			setStatus(phase, makeText(timeLeft), timeLeft)
		end
		if stopWhen and stopWhen() then
			return true
		end
		task.wait(0.1)
	end
	return stopWhen ~= nil and stopWhen() == true
end

local function playPressAnimation()
	local home = cap.CFrame
	local down = TweenService:Create(cap, TweenInfo.new(0.12, Enum.EasingStyle.Quad, Enum.EasingDirection.In), {

local function runRound()
	while #Players:GetPlayers() < GameConfig.MinPlayers do
		setStatus("Waiting", "Waiting for players (" .. #Players:GetPlayers() .. "/" .. GameConfig.MinPlayers .. ")", 0)
		task.wait(1)
	end
	countdown(GameConfig.IntermissionTime, "Intermission", function(timeLeft)
		return "Next round in " .. timeLeft .. "..."
	end)

	-- 1. Teleport everyone with a living character into the arena
	ArenaBuilder.Reset()
	local roundPlayers = {}
	for _, player in ipairs(Players:GetPlayers()) do
		local character = player.Character
		local humanoid = character and character:FindFirstChildOfClass("Humanoid")
		if humanoid and humanoid.Health > 0 and character:FindFirstChild("HumanoidRootPart") then
			character:PivotTo(CFrame.new(ArenaBuilder.GetRandomSpot(3)))
			participants[player] = true
			table.insert(roundPlayers, player)
			table.insert(diedConnections, humanoid.Died:Connect(function()
				eliminate(player)
			end))
		end
	end
	if not anyoneLeft() then
		return
	end
	roundNumber = roundNumber + 1 -- only rounds somebody actually played count
	local difficultyName = RoundLogic.GetDifficultyName(GameConfig, roundNumber)
	local difficulty = GameConfig.Difficulties[difficultyName]
	ReplicatedStorage:SetAttribute("Round", roundNumber)
	ReplicatedStorage:SetAttribute("Difficulty", difficultyName)

	-- 2. The button phase: 20 seconds of temptation
	buttonArmed = true
	prompt.Enabled = true
	countdown(GameConfig.ButtonPhaseTime, "Button", function(timeLeft)
		return "DON'T PRESS THE BUTTON! " .. timeLeft
	end, function()
		return presser ~= nil or not anyoneLeft()
	end)
	buttonArmed = false
	prompt.Enabled = false
	if not anyoneLeft() then
		for _, player in ipairs(roundPlayers) do
			if player.Parent then
				CoinManager.AddCoins(player, GameConfig.Rewards.Participation)
			end
		end
		return
	end

	if presser == nil and not GameConfig.AutoPressWhenTimeUp then
		setStatus("Results", "Nobody pressed it. Boring... but safe.", 0)
		for _, player in ipairs(roundPlayers) do
			if player.Parent then
				CoinManager.AddCoins(player, GameConfig.Rewards.Participation)
			end
		end
		task.wait(GameConfig.ResultsTime)
		return
	end

	-- 3. Somebody pressed it (or the button got impatient)
	local presserName = presser and presser.Name
	playPressAnimation()
	fxRemote:FireAllClients("Flash")
	fxRemote:FireAllClients("Shake", 0.8, 0.6)
	local event = RoundLogic.PickEvent(GameConfig, roundNumber, lastEventName)
	lastEventName = event.Name
	if presserName then
		setStatus("Pressed", presserName .. " PRESSED THE BUTTON!", 0)
	else
		setStatus("Pressed", "Nobody pressed it... so it pressed ITSELF!", 0)
	end
	task.wait(2)
	fxRemote:FireAllClients("Banner", event.DisplayName)
	ArenaBuilder.LiftButton(30)

	-- 4. Run the event
	local eventModule = eventsFolder:FindFirstChild(event.Name)
	if not eventModule then
		error("No ModuleScript named '" .. event.Name .. "' inside ServerScriptService > Events")
	end
	local context = {
		Settings = difficulty[event.Settings],
		Arena = ArenaBuilder,
		Folder = ArenaBuilder.GetEventFolder(),
		GetAlive = getAlive,
		FX = function(...)
			fxRemote:FireAllClients(...)
		end,
	}
	local ok, result = pcall(function()
		return require(eventModule).Start(context)
	end)
	if ok then
		stopEvent = result
	else
		warn("[RoundManager] " .. event.Name .. " crashed when starting: " .. tostring(result))
	end
	countdown(difficulty.EventTime, "Event", function(timeLeft)
		return event.DisplayName .. "  " .. timeLeft
	end, function()
		return not anyoneLeft()
	end)
	if stopEvent then
		pcall(stopEvent)
		stopEvent = nil
	end

	-- 5. Rewards
	local survivorCount = 0
	for _, player in ipairs(roundPlayers) do
		if player.Parent then
			local survived = participants[player] == true
			local coins = RoundLogic.CalculateReward(GameConfig, difficultyName, survived, player == presser)
			CoinManager.AddCoins(player, coins)
			if survived then
				survivorCount = survivorCount + 1
				CoinManager.AddSurvived(player)
				fxRemote:FireClient(player, "Banner", "YOU SURVIVED! +" .. coins .. " coins")
			else
				fxRemote:FireClient(player, "Banner", "Better luck next time. +" .. coins .. " coins")
			end
		end
	end
	setStatus("Results", survivorCount .. " of " .. #roundPlayers .. " survived!", 0)
	task.wait(GameConfig.ResultsTime)

	-- 6. Survivors go back to the lobby (eliminated players already respawned there)
	for player in pairs(participants) do
		if player.Character then
			player.Character:PivotTo(CFrame.new(ArenaBuilder.GetLobbySpot()))
		end
	end
end

---------------------------------------------------------------------

	if not ok then
		warn("[RoundManager] Round crashed: " .. tostring(err))
		setStatus("Waiting", "Oops! Restarting the round...", 0)

-- RollingBall (ModuleScript inside ServerScriptService > Events)
-- A giant ball picks a victim, pauses, then charges in a straight line. Side-step it!

local ReplicatedStorage = game:GetService("ReplicatedStorage")

local GameConfig = require(ReplicatedStorage:WaitForChild("GameConfig"))

local RollingBall = {}

local AIM_PAUSE = 0.6 -- seconds the ball "thinks" before each charge (your chance to dodge)

local function runBall(context, ball, isRunning)
	local settings = context.Settings
	local arena = context.Arena
	local radius = settings.Size / 2
	local limit = arena.Width / 2 - radius
	local center = arena.Center
	local y = arena.FloorY + radius
	local position = ball.Position
	local spin = CFrame.new()

	while isRunning() do
		-- 1. pick a target and aim
		local alive = context.GetAlive()
		local direction
		if #alive > 0 then
			local target = alive[math.random(1, #alive)].Root.Position
			direction = Vector3.new(target.X - position.X, 0, target.Z - position.Z)
		end
		if direction == nil or direction.Magnitude < 1 then
			local angle = math.random() * math.pi * 2
			direction = Vector3.new(math.cos(angle), 0, math.sin(angle))
		end
		direction = direction.Unit
		task.wait(AIM_PAUSE)

		-- 2. charge until we hit a wall
		local hitWall = false
		while isRunning() and not hitWall do
			local elapsed = task.wait()
			local nextPosition = position + direction * settings.Speed * elapsed
			local offsetX = nextPosition.X - center.X
			local offsetZ = nextPosition.Z - center.Z
			if math.abs(offsetX) > limit or math.abs(offsetZ) > limit then
				hitWall = true
				offsetX = math.clamp(offsetX, -limit, limit)
				offsetZ = math.clamp(offsetZ, -limit, limit)
			end
			position = Vector3.new(center.X + offsetX, y, center.Z + offsetZ)

			-- make it look like it's rolling
			local rollAxis = Vector3.new(direction.Z, 0, -direction.X)
			spin = CFrame.fromAxisAngle(rollAxis, settings.Speed * elapsed / radius) * spin
			ball.CFrame = CFrame.new(position) * spin

			for _, info in ipairs(context.GetAlive()) do
				if (info.Root.Position - position).Magnitude < radius + 1.5 then
					info.Humanoid.Health = 0
				end
			end
		end
		if hitWall then
			context.FX("Shake", 0.6, 0.4)
		end
	end
end

function RollingBall.Start(context)
	local settings = context.Settings
	local running = true
	local function isRunning()
		return running
	end

	for i = 1, settings.Count do
		local ball = Instance.new("Part")
		ball.Name = "GiantBall" .. i
		ball.Shape = Enum.PartType.Ball
		ball.Size = Vector3.new(settings.Size, settings.Size, settings.Size)
		ball.Anchored = true -- the script moves it, so physics can't fling it out of the arena
		ball.CanCollide = false
		ball.Color = GameConfig.Colors.Ball
		ball.Material = Enum.Material.SmoothPlastic
		-- start in a corner, away from the middle
		local corner = (i % 2 == 1) and 1 or -1
		local start = context.Arena.Center + Vector3.new(corner, 0, corner) * (context.Arena.Width / 2 - settings.Size / 2)
		ball.Position = Vector3.new(start.X, context.Arena.FloorY + settings.Size / 2, start.Z)
		ball.Parent = context.Folder
		task.spawn(runBall, context, ball, isRunning)
	end

	return function()
		running = false
	end
end

-- CoinManager (ModuleScript in ServerScriptService)
-- Shows Coins and Survived on the leaderboard and saves them between visits.

local DataStoreService = game:GetService("DataStoreService")
local Players = game:GetService("Players")
local ReplicatedStorage = game:GetService("ReplicatedStorage")

local GameConfig = require(ReplicatedStorage:WaitForChild("GameConfig"))

local CoinManager = {}

local AUTOSAVE_SECONDS = 120
local LOAD_TRIES = 3

local store = nil
local loadedOk = {} -- [player] = true once their saved data loaded safely
local saving = {} -- [player] = true while a save is running (so we never save twice at once)

local function keyFor(player)
	return "player_" .. player.UserId
end

local function getStat(player, statName)
	local leaderstats = player:FindFirstChild("leaderstats")
	return leaderstats and leaderstats:FindFirstChild(statName)
end

local function loadData(player)
	local ok, data
	for try = 1, LOAD_TRIES do
		ok, data = pcall(function()
			return store:GetAsync(keyFor(player))
		end)
		if ok then
			return true, data
		end
		task.wait(try) -- wait a little longer each time
	end
	return false, data
end

local function onPlayerAdded(player)
	-- Load first, THEN show the stats, so the numbers never jump from 0 to the saved amount.
	local saved = nil
	if store then
		local ok, data = loadData(player)
		if ok then
			saved = data
			loadedOk[player] = true
		else
			-- Never save over data we couldn't read, or we might wipe someone's coins.
			warn("[CoinManager] Couldn't load data for " .. player.Name .. ", progress won't save this visit: " .. tostring(data))
		end
	end
	if player.Parent == nil then
		loadedOk[player] = nil
		return -- they left while we were loading
	end

	-- "leaderstats" is a special name: Roblox shows these values on the player list.
	local leaderstats = Instance.new("Folder")
	leaderstats.Name = "leaderstats"
	local coins = Instance.new("IntValue")
	coins.Name = "Coins"
	coins.Parent = leaderstats
	local survived = Instance.new("IntValue")
	survived.Name = "Survived"
	survived.Parent = leaderstats
	if type(saved) == "table" then
		coins.Value = tonumber(saved.Coins) or 0
		survived.Value = tonumber(saved.Survived) or 0
	end
	leaderstats.Parent = player
end

local function save(player)
	if not (store and loadedOk[player]) or saving[player] then
		return
	end
	local coins = getStat(player, "Coins")
	local survived = getStat(player, "Survived")
	if not (coins and survived) then
		return
	end
	local data = { Coins = coins.Value, Survived = survived.Value }
	saving[player] = true
	local ok, err = pcall(function()
		store:UpdateAsync(keyFor(player), function(old)
			-- Coins only ever go up. If the stored number is already higher (another server
			-- saved more recently), keep it: returning nil means "don't change anything".
			-- (If you add a shop where coins get SPENT, this check must change. See Level 3.)
			if type(old) == "table" and (tonumber(old.Coins) or 0) > data.Coins then
				return nil
			end
			return data
		end)
	end)
	saving[player] = nil
	if not ok then
		warn("[CoinManager] Save failed for " .. player.Name .. ": " .. tostring(err))
	end
end

function CoinManager.Setup()
	if GameConfig.SaveData then
		local ok, result = pcall(function()
			return DataStoreService:GetDataStore(GameConfig.DataStoreName)
		end)
		if ok then
			store = result
		else
			warn("[CoinManager] Saving is off (turn on API access in Experience Settings > Security): " .. tostring(result))
		end
	end

	Players.PlayerAdded:Connect(onPlayerAdded)
	for _, player in ipairs(Players:GetPlayers()) do
		task.spawn(onPlayerAdded, player)
	end

	Players.PlayerRemoving:Connect(function(player)
		while saving[player] do
			task.wait(0.1) -- an autosave is running; wait, then save the final numbers
		end
		save(player)
		loadedOk[player] = nil -- so the shutdown save below skips them
	end)

	-- When the server shuts down, save everyone still here, then wait for every save to finish.
	game:BindToClose(function()
		for _, player in ipairs(Players:GetPlayers()) do
			task.spawn(save, player)
		end
		while next(saving) ~= nil do
			task.wait(0.1)
		end
	end)

	task.spawn(function()
		while true do
			task.wait(AUTOSAVE_SECONDS)
			for _, player in ipairs(Players:GetPlayers()) do
				task.spawn(save, player)
			end
		end
	end)
end

function CoinManager.AddCoins(player, amount)
	local coins = getStat(player, "Coins")
	if coins then
		coins.Value = coins.Value + amount
	end
end

function CoinManager.AddSurvived(player)
	local survived = getStat(player, "Survived")
	if survived then
		survived.Value = survived.Value + 1
	end
end

function CoinManager.GetCoins(player)
	local coins = getStat(player, "Coins")
	return coins and coins.Value or 0
end

return CoinManager

Puts Coins and Survived on the player list. It also saves them, once you turn saving on in Step 11. Until then the game still runs and Output shows one friendly warning.
