Zero Product Rule
If $ab = 0$, then $a = 0$ or $b = 0$.
  1. Move everything to one side so it equals 0.
  2. Factor completely (GCF first!).
  3. Set each factor equal to 0 and solve.
  4. Check your answers.
Example: $x^2 - 5x = -6$
$$x^2-5x+6=0 \;\Rightarrow\; (x-2)(x-3)=0 \;\Rightarrow\; x=2,\; x=3$$
Example: $2x^3 - 18x = 0$
$$2x(x^2-9)=0 \;\Rightarrow\; 2x(x-3)(x+3)=0 \;\Rightarrow\; x=0,\,3,\,-3$$

Trap: it only works when one side is 0. $(x-1)(x+2)=4$ does NOT mean $x-1=4$. Also don't divide both sides by $x$ — you lose the $x=0$ answer.

2

Rational Expressions & Functions
A rational expression is $\dfrac{p}{q}$ (polynomials) where $q \ne 0$.
  • Domain: set the denominator $= 0$ and solve. Those x-values are excluded.
  • Simplify: factor top and bottom, then cancel common factors.
  • Opposites: $\dfrac{a-b}{b-a} = -1$
Example: simplify and state the domain
$$\frac{x^2-9}{x^2+x-6}=\frac{(x-3)(x+3)}{(x+3)(x-2)}=\frac{x-3}{x-2}$$
Domain: $x \ne -3,\ x \ne 2$  (use the original denominator).

Function form: $f(x)=\dfrac{x+1}{x-4}$ has domain $\{x \mid x \ne 4\}$, or $(-\infty,4)\cup(4,\infty)$.

Trap: you can only cancel factors, not terms. $\dfrac{x+5}{5} \ne x$.

3

Multiplying & Dividing
$\dfrac{a}{b}\cdot\dfrac{c}{d}=\dfrac{ac}{bd}$    $\dfrac{a}{b}\div\dfrac{c}{d}=\dfrac{a}{b}\cdot\dfrac{d}{c}$
  1. Dividing? Flip the second fraction and change ÷ to ×.
  2. Factor every numerator and denominator.
  3. Cancel common factors (top with any bottom).
  4. Multiply what's left.
Example:
$$\frac{x^2-4}{3x}\div\frac{x+2}{6x^2}=\frac{(x-2)(x+2)}{3x}\cdot\frac{6x^2}{x+2}=2x(x-2)$$

Trap: flip only the fraction AFTER the ÷ sign — never the first one.

4

Adding & Subtracting
You need a common denominator (LCD). Then $\dfrac{a}{c}\pm\dfrac{b}{c}=\dfrac{a\pm b}{c}$.
  1. Factor each denominator.
  2. LCD = every different factor, each at its highest power.
  3. Multiply each fraction's top and bottom by whatever it's missing.
  4. Combine numerators (use parentheses when subtracting!).
  5. Simplify and factor if possible.
Example:
$$\frac{3}{x-2}-\frac{1}{x+1}=\frac{3(x+1)-(x-2)}{(x-2)(x+1)}=\frac{2x+5}{(x-2)(x+1)}$$

Trap: the minus sign hits the WHOLE second numerator: $-(x-2) = -x+2$.

5

Complex Fractions
A fraction with fractions inside its top and/or bottom.

Method 1: make the top one fraction, make the bottom one fraction, then divide (flip and multiply).

Method 2 (usually faster): multiply the top AND bottom by the LCD of all the little fractions.

Example (Method 2, LCD = $x^2$):
$$\frac{1+\frac{1}{x}}{1-\frac{1}{x^2}}\cdot\frac{x^2}{x^2}=\frac{x^2+x}{x^2-1}=\frac{x(x+1)}{(x+1)(x-1)}=\frac{x}{x-1}$$

Trap: multiply EVERY term by the LCD, including whole numbers like the 1's.

6

Solving Rational Equations
Equation (has =)? Multiply everything by the LCD to clear the fractions. Expression (no =)? Keep the LCD in the denominator.
  1. Find the restrictions (values that make any denominator 0).
  2. Multiply every term on both sides by the LCD.
  3. Solve the equation that's left (might need zero product rule).
  4. Throw out any answer that's a restricted value (extraneous).
Example: $\dfrac{2}{x}+\dfrac{1}{3}=1$   (LCD $=3x$, $x\ne0$)
$$6 + x = 3x \;\Rightarrow\; 6 = 2x \;\Rightarrow\; x = 3 \;\checkmark$$
Extraneous example: $\dfrac{x}{x-3}=\dfrac{3}{x-3}+2$   ($x\ne3$)
$$x = 3 + 2(x-3) \;\Rightarrow\; x = 2x-3 \;\Rightarrow\; x=3$$
But $x=3$ is restricted, so there is no solution.

Trap: always check restrictions at the end — an answer that makes a denominator 0 doesn't count.

7

Applications & Proportions
Proportion: $\dfrac{a}{b}=\dfrac{c}{d} \;\Rightarrow\; ad = bc$ (cross-multiply).
  • Proportions / scale / similar triangles: keep the same units in the same spots on both sides.
  • Work: $\dfrac{1}{a}+\dfrac{1}{b}=\dfrac{1}{t}$  ($a,b$ = each one's time alone, $t$ = time together)
  • Distance, rate, time: $d = rt$, so $t = \dfrac{d}{r}$. With a current or wind: downstream $r+c$, upstream $r-c$.
Proportion: 3 in on a map = 50 mi. How far is 7.5 in?
$$\frac{3}{50}=\frac{7.5}{x}\;\Rightarrow\;3x=375\;\Rightarrow\;x=125\text{ mi}$$
Work: Pipe A fills a pool in 3 h, Pipe B in 6 h. Together?
$$\frac13+\frac16=\frac1t \;\Rightarrow\; 2t + t = 6 \;\Rightarrow\; t=2\text{ h}$$
Current: Boat goes 20 mph in still water. It travels 36 mi downstream in the same time as 24 mi upstream. Find the current $c$.
$$\frac{36}{20+c}=\frac{24}{20-c}\;\Rightarrow\;720-36c=480+24c\;\Rightarrow\;c=4\text{ mph}$$

Trap: in "same time" problems, set the two times ($d/r$) equal to each other.

Factor first. Watch the denominators. Check your answers.
